# FastAPI REST API

This is a simple FastAPI REST API project.

## Getting Started

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the server:
   ```bash
   uvicorn main:app --reload
   ```

Visit http://127.0.0.1:8000 to see the API.

## Example Endpoint
- `GET /` returns `{ "Hello": "World" }`
